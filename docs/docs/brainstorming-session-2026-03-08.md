### Technique 3: SCAMPER - Fonctionnalités de Conversion

*Objectif: Générer systématiquement des fonctionnalités innovantes.*

| Lettre | Question | Idée |
|--------|----------|------|
| **S** - Substitute | Remplacer le formulaire classique | ~~Chatbot "Coach virtuel" qui qualifie le besoin~~ *(écarté, trop lourd à produire pour l'apport attendu)* |
| **C** - Combine | Combiner éléments | Calendrier simple des lieux et événements du mois *(simplifié : plus de carte interactive combinée)* |
| **A** - Adapt | Adapter d'ailleurs | ~~Système de réservation type Doctolib pour séance découverte~~ *(écarté, formulaire de contact suffisant)* |
| **M** - Modify | Amplifier | ~~Galerie immersive 360° d'une séance de boxe~~ → Galerie photo classique (événements, cours, galas) |

4. Actualités / fil de vie de l'association
5. Flux réseaux sociaux intégré

## Ajustements Post-Session (2026-07-06)

Suite à une revue des idées avec le comité, les arbitrages suivants ont été retenus :

- **Écarté** : Chatbot "Coach virtuel", galerie immersive 360°, système de réservation type Doctolib — jugés trop coûteux à produire/maintenir pour l'apport attendu sur un site vitrine associatif.
- **Simplifié** : Le duo "calendrier interactif + carte des interventions" devient un calendrier simple informant des lieux et événements du mois à venir.
- **Ajouté** : Galerie photo classique, actualités/fil de vie de l'association, formulaire d'adhésion pour les particuliers (public cible initial jusqu'ici peu couvert), flux réseaux sociaux intégré.

Voir le document `fonctionnalites-site-cbac.md` pour la liste consolidée des fonctionnalités retenues.
